# Ordinary resumable examples

[coco-resumable.yaml](coco-resumable.yaml) and [hellaswag-resumable.yaml](hellaswag-resumable.yaml) reference the supplied task settings and shared `model_config: ../model.yaml`. These files live one directory below `configs`, so that reference resolves to the existing shared design. COCO changes `data.num_workers` from four to zero and explicitly adds `training.save_steps: [100, 500]`, preserving selection at500 and the500-update budget. The nonterminal `step_000100.pt` supports continuation after a finalized interruption; the extra save does not create `last.pt`. These are named example settings, not a global save-cadence policy. HellaSwag already uses zero workers, but its default fixed-presentation loader cannot exactly continue. The named HellaSwag example sets `training.presentation_stream: null` to select the ordinary map loader, preserving prompts, objectives, update budget and paired randomness while changing sampling/presentation policy. Bind it as a fresh scientific identity; it is not the unchanged September default. Set this before binding a run: changing YAML after binding cannot retrofit exact continuation.

Follow [operations commands](../../docs/operations-workflow.md) for fresh roots, checks, explicit saved checkpoints, independent evaluation and collection. These are ordinary task examples, not reduced smoke budgets. Task-specific prompts, objectives, update budgets and evaluation settings remain intact; [current defaults](../../docs/current-defaults.md) records their lineage.
